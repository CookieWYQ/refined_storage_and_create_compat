## 一、序列装配样板终端（SPT）——含一次**理念变更**

### 1.1 理念变更（最重要，先理解再动手）

- **删掉「单元样板库」与「装配编排」这两个 Tab 以及它们背后的整套概念**：
  机器的问题已经解决，**不需要玩家手写单元样板**；单元样板应**自动生成**。

- 顶部**操作槽三格（装配 / 输入 / 输出）→ 只保留一个口**，就是「输入原料」。
  产出完全由**产物区**表达，**不需要**单独的输出槽；「产物有就够了」。

- **产物与废料都允许重复**（同一种可以出现多条），每个产物的**概率自动从序列装配配方读取**（不要求玩家手填）。

- **搜索框只用来过滤「流程编排」**，不再过滤单元样板库。

- **允许流程编排为 0 步**（空编排，要正确渲染与保存）。

- 顶部现在的「单元样板库 / 装配编排」两个按钮点了没反应 —— 按上面前提，**直接删掉**这两个 Tab。

- 左上角标题疑似被遮挡，**标题要能正常显示**（别被背景元素压住）。

### 1.2 必须修的 bug

1. **产物区的概率与物品图标重叠**：概率现在画在物品**下面、看不清**。

   - 概率要画在**可见**的位置（例如物品图标的右下角、并在图标之上），与图标错开。

   - 同时确认**概率是否真的从序列装配配方里读到了数据**（用户看不清所以无法确认）。
2. **产物槽现在是"能拿出来的"**，而它应当是**标记位（ghost）**：只能标记、不可取出物品。
3. **滚动条全都没生效/没做出来**：产物区滚动条、废料区滚动条、流程编排滚动条 —— 三个都要真正可用（背景有轨道、滑块可拖、滚轮可用）。
4. **生成不了样板，也生成不了单元样板**（点生成没反应）→ 修好生成流程。
5. **执行仓界面里的「配置」按钮点不了（是灰的）** → 修好（应可点击并打开配方类型/名字配置）。
6. 「导入配方」到底做什么用的？用户预期：**像精密构件那种序列装配配方，应当能直接一键转移进来**（不必先点某个 `+`）。
   → 把「导入配方」做成明确的入口，并给出可见反馈。

### 1.3 交互重做（流程编排）

现在只有 Shift+滚轮增减，**太难受**。要求：

- **保留** Shift+滚轮 这类快捷操作（保留基础操作）；

- **新增：组合键（例如 Ctrl+左键）点击某一行 → 打开一个「详细配置界面」**，在该界面里用**输入框**直接配置：
  循环次数、绑定的机器（以及其它该行可配的东西）；

- 该详细配置界面要按工程既有子界面风格做（参考 `CollectionMarkerConfigScreen`），确定/取消，服务端权威。

### 1.4 布局清理

- **删掉流程编排的** **`−`** **/** **`+`** **步数按钮**（没必要，`−` 更没意义）。

- 「循环次数」目前**没有任何文字提示**（加减按钮只能靠 tooltip 才知道）→ 要有明确 label。

- 整体排版再检查一遍，别再有文字压背景/压槽位。

## 四、高级物品定量保持器（AdvancedQuantityKeeper）

1. **贴图本身没问题**，但**背景不符合要求**：用户强调背景要用**他提供的工具**生成的那种（圆角、高亮/凹凸质感、与其它界面统一的规格），**不是让 AI 手绘自由发挥**。
   → 输出给绘图工具的技术文档时，**必须显式强调**：按给定几何 + 规定配色/边框规格用工具生成，不要自创画风。
2. **单位位置放错**（数量/单位文字位置不对）。
3. **只显示一个 ✗**，没有像原版定量保持器那样显示：

   - **已存多少个**（数量）

   - **是否自动销毁（过量销毁）** 的状态
4. **一个按钮不能同时控制两件事**：需要能**分别**控制「是否自动合成」与「是否过量销毁」。
   （注：用户说"只要放入一个自动合成插件，就可以控制所有槽位的是否自动合成" → 即**自动合成是全局由升级决定的**，而"是否过量销毁"是每槽可配的开关，两个要分开表达。）
5. **加减按钮没了** → 目标数量的 `+` / `−` 按钮要补回来（或等价的加减交互）。

## 五、技术文档写作要求（以后所有 GUI 文档都适用）
