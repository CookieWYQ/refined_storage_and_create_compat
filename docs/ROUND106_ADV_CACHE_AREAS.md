# 高级归流缓存仓 · 区域与过滤器（第 106 轮交互说明）

> 面向玩家与交付说明的一页纸：**区域怎么选、过滤器怎么配、框怎么显示**。
> 对应实机反馈（1.2.0-beta.9）第 1~6 条与第 107 条（物品只显示名字、id 进 tooltip）。
> 代码入口：`client/screen/AdvancedCollectionCacheScreen.java`、`client/screen/AreaSelectorScreen.java`、
> `network/AdvancedAreaSnapshotPacket.java`、`block/entity/AdvancedCollectionCacheBlockEntity.java`。

## 0. 一句话版本

- **能吸的地方 = 区域选定器里那些「真的可用」的区域**（维度一致、没超上限）。列表里看不到的区域 = 不参与扫描。
- **每个区域吸什么 = 该区域的过滤标记**；现在**一屏就能看到**（状态带右侧的物品图标），
  并且有两条直达编辑的路，不用再记住「过滤器藏在方块里」。
- **「单显 / 全显」两颗按钮**随时能在世界里画橙框：单显 = 当前这个区域，全显 = 全部可用区域。
- 界面不再显示「没匹配到 / 数量没达到」这类红字；只有「真的会让机器停摆」的原因才上屏。

## 1. 主界面（高级归流缓存仓）

界面底部左侧：`区域选定器槽` → `[区域]` 按钮 →（右侧空白带）`[范围]`（= 全显）、`[单显]`。

### 状态带（Menu y210 整行留白）说什么

| 情况 | 显示内容 |
|---|---|
| 没装选定器 / 选定器里没有区域 / 维度不符 | 一句**为什么一点都不吸**（这三条会整段跳过吸收） |
| 未接 RS 网络 / 未激活 | 灰字：不会吸收 |
| 缓存已满 | 「缓存已满，暂存不下（不丢，稍后重试）」 |
| 其它（正常运转） | 「区域 2/3 · 只吸 4 种」+ **右端直接画这 4 个物品图标** |

> 已删除（用户第 3 条明确要求）：`没有生效的过滤标记` / `范围内没有匹配的掉落物` /
> `命中了但没凑够标记要求的数量` / `物品吸取开关是关的` 这四句红字。
> 它们只是「这一轮没货 / 还差几件」或「你自己关的开关」，不是故障；过滤配没配现在由图标直显表达。

### 状态带右端的过滤图标

- 图标 = **当前正在编辑过滤的那个区域**吸的物品（与下方 48 格 ghost 窗口同一份数据）。
- 最多画 5 个；悬停任一图标/整条带 → 完整 tooltip：物品**名字** + 「物品 ID：…」+ 需求数量。
- **点这排图标** = 打开区域列表（去选别的区域 / 编辑它的过滤）。

## 2. 区域列表（点 `[区域]`）

左边一屏可读的区域列表，右边是精确编辑（6 个坐标 + 名称）。

### 列表里只会出现「真的可用」的区域

服务端算好一份**区域快照**下发（`AdvancedAreaSnapshotPacket`），客户端只画这一份：

- 维度不符 / 超出 Config 上限（个数 / 单边 / 体积）/ 选定器为空 ⇒ **不列**；
- 被排除的区域个数会写在列表底部（例：「另有 2 个区域不参与扫描（维度不符 / 超出上限）」），不静默；
- 每行的**序号就是区域在选定器里的原始序号**，因此和主界面的「区域 N/M」对得上。

### 每行显示什么

- 第一行：`序号. 名字`（没起名 = 「区域 N」）；
- 第二行（放不下就拆成两行）：`从 x,y,z` / `到 x,y,z` —— **不省略、不截断**，放不下只缩字号；
- 行右侧：该区域过滤标记的**物品图标摘要**（最多 3 个）；
- 悬停任意一行：完整坐标 + 尺寸 + 维度 + 该区域过滤（物品**名字** + 「物品 ID：…」）。

### 点行的两种效果

| 点哪里 | 效果 |
|---|---|
| 行的普通区域 | 选中该行（并把它设成「正在编辑过滤的区域」），世界里立即**单显**该区域 |
| 行右侧的图标区 | 选中 + 直接进入「编辑该区域过滤」流程（见下） |

### 编辑某个区域的过滤器（两条直达路，都不用记住路径）

1. **行内图标**：点某行右侧的过滤图标 → 自动回到机器界面，48 格 ghost 窗口已经是该区域的过滤；
2. **右侧按钮**：选中一行 → 右侧面板底部 `[编辑过滤]` → 同样回到机器界面。

> 落到机器界面后：匹配区标题带会显示「区域 2/3 · 只吸 4 种」，把物品点进 ghost 格就是给
> **这个区域**加过滤条目；空集 = 这个区域**不吸任何东西**（安全默认，避免两台机器互相吸放）。

### 服务端校验与拒绝原因（用户第 5 条）

点行 / 建区域 / 改区域时，服务端都会再校验一次。**校验不过不再静默**：

| 原因 | 界面提示 |
|---|---|
| 区域不存在（列表过期） | 「该区域已不存在：列表已按服务端刷新」 |
| 维度不符 | 「选定器绑定的维度与当前维度不符：请先点『改绑维度』」 |
| 已达个数上限 | 「区域数量已达上限」 |
| 几何重复 | 「已存在相同区域（同维度、同坐标）」 |
| 几何非法（越界 / 超单边 / 超体积） | 「区域几何不合法（越界 / 超单边 / 超体积）」 |

拒绝原因随快照下发（`rejectCode` + 单调 `rejectSeq`，只在序号变大时提示一次，不刷屏）；
列表本身每 tick 跟随服务端最新快照，所以「刷新列表」是自动的。

## 3. 「显示区域」：单显 / 全显（用户第 6 条）

| 按钮 | 画什么 | 什么时候不画 |
|---|---|---|
| `[单显]` | 只画**当前编辑的那个**区域 | 还没选区域 ⇒「还没有选中区域：点『区域』→ 列表里点一行的『编辑过滤』」 |
| `[范围]`（= 全显） | 画**全部可用区域** | 没装选定器 / 区域为空 / 维度不符 ⇒ 按原因提示，一个框都不画（此时机器一点不吸，画半径框就是谎报） |

- 样式统一：**橙色 `#FF9F1C` + 棋盘面贴图 + 1/16 线宽**（与范围充电器、区域选定器同一套；`AreaOutline`）。
- **每个盒子一个独立 Outliner slot，显示窗口内每 tick 全量重喂** ⇒ 多区域同时显示不会互相覆盖、
  不会「一个还在一个提前消失」。
- 显示 5 秒；**显示中再点一次立即关闭**；**关界面不会立刻删框**，而是按剩余时长重新武装一次，
  所以在世界界面外还能把框看完。
- 若描边渲染出口不可用（Ponder/Outliner 被禁用），会明说「描边渲染不可用（Outliner 未就绪）」，不静默。

区域列表界面里的描边：选中行 = 单显；`[显示全部：开/关]` = 全显；关界面同样按 5 秒重新武装。

## 4. 物品显示口径（第 107 条）

凡是出现「物品候选 / 已选物品」的列表与摘要（本轮 = 过滤图标摘要、区域行摘要、过滤 tooltip）：

- **行内 / 摘要只显示本地化物品名**（中文环境就是中文名），**不印注册 id**；
- **完整注册 id 只在 tooltip** 里给一行「物品 ID：…」；
- 搜索（若该界面有搜索框）同时匹配**名字子串**与**注册 id 子串**，都不区分大小写。

## 5. 服务端权威边界（给维护者）

| 数据 | 谁算 | 客户端做什么 |
|---|---|---|
| 哪些区域可用（维度 / 上限 / 顺序） | 服务端 `buildAreaSnapshot()` | 只画 |
| 每个区域吸什么（过滤图标） | 服务端 `snapshotFilterIcons()` | 只画图标（名字/id 走 tooltip） |
| 拒绝原因 | 服务端 `AreaSelectorEditPacket#reject(...)` | 翻成一句人话 |
| 画框几何 | 服务端下发的 `Area`（方块闭区间） | `Area → AABB` 一个转换 |
| 吸收判定 / 每 tick 扫描 | 服务端 | 不参与 |

快照只在「区域数据 / 编辑上下文 / 拒绝序号」变化时推送（`broadcastChanges` 里按版本号比较），
不是每 tick 全量刷。
