# 单条资料正文模板（复制到 `entries/<slug>/body.md` 后改写）

<!-- 文件头不要写 YAML；元数据统一在 inventory.csv，写手只交 body.md + facts.md -->

**（首段）** 一句话说清它是什么、属于本模组的哪条链路。第二句写它在流程里的职责，或者没有它时会发生什么。

**用途**

交互方式（右键打开界面 / 潜行右键取下 / 界面按钮 / 快捷键）与它能做的事。一两句一段，超过两句就拆段。

**参数**（只有确实存在多项数值/档位时才保留本节）

| 项目 | 说明 |
| --- | --- |
| **项目名** | 数值与单位、默认值、可配置范围。 |

**获取**

合成表来源、是否需要先有某台机器、创造模式是否可获得。写不出真实途径时照实写"仅创造模式可获取"。

**注意**

前置条件、限制、已知问题；没有就删掉本节。
