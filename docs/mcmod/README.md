MC百科资料页工程的**唯一正式目录**是仓库根目录的 `mcmod/`（见 `mcmod/README.md`）。

- `mcmod/style-contract.md` — 写作硬约束（正式版）

- `mcmod/entries/` — 28 条正文与证据表
- `mcmod/html/` — 可直接粘贴的百科 HTML 片段
